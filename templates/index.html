About the Project

EmoSense: AI-Based Facial Emotion
Detection & Wellness System

An intelligent real-time web application built with deep learning and computer vision, capable of detecting and analyzing human emotions from facial expressions — and delivering personalized emotional wellness support.

EmoSense is an intelligent real-time system capable of detecting and analyzing human emotions from facial expressions using Convolutional Neural Networks (CNN). Developed as a major academic project at the School of Engineering, Pokhara University, this system represents a convergence of computer vision, deep learning, and emotional wellness support, designed to bring emotional intelligence into everyday digital interactions.

The system identifies seven basic emotions — Angry, Disgust, Fear, Happy, Sad, Surprise, and Neutral — using a CNN model trained on publicly available datasets including FER2013, the Emotion Recognition in Nepali Ethnic Faces dataset, and the CK+ (Extended Cohn-Kanade) Dataset. Data augmentation techniques including rotation, flipping, scaling, and brightness adjustment are applied to improve model accuracy, robustness, and reliability across diverse real-world conditions.

Beyond detection, EmoSense integrates advanced wellness-oriented features: user authentication and secure account management, comprehensive emotion history tracking, daily diary management, AI chatbot interaction that responds based on the user's detected emotional state, personalized music and video recommendations, daily inspirational quotes, and emergency email notifications via SMTP for critical emotional conditions — all delivered through a Flask-based web application with a clean, accessible interface.

This project demonstrates real-world applications of deep learning contributing to mental health assistance, smart healthcare, educational environments, customer experience analysis, and the development of emotionally intelligent AI systems that respond naturally to human needs. The inclusion of the Nepali Ethnic Faces dataset also addresses cultural diversity in facial recognition, making the model more inclusive and relevant for South Asian users.

Training Data
Datasets Used for Training
FER-2013

The primary training dataset by Goodfellow et al. (2013), containing thousands of grayscale 48×48 facial images collected from the internet. It covers diverse lighting conditions, facial orientations, and occlusions across all seven emotion categories, making the model robust for real-world use.

CK+ Dataset

The Extended Cohn-Kanade Dataset by Kanade, Cohn & Tian (2000), containing labeled facial image sequences with detailed landmark and action unit annotations, ranging from neutral expressions to peak emotional expressions. A standard benchmark for FER research worldwide.

Nepali Ethnic Faces

The Emotion Recognition in Nepali Ethnic Faces dataset, ensuring cultural diversity and significantly improving the model's performance on South Asian facial features and expressions. This makes EmoSense more inclusive and accurate for Nepali and regional users.

📁 config/db.php — Database Connection
<?php
// config/db.php
define('DB_HOST', 'localhost');
define('DB_USER', 'root');       // XAMPP default
define('DB_PASS', '');           // XAMPP default (empty)
define('DB_NAME', 'emosense_db');

$conn = mysqli_connect(DB_HOST, DB_USER, DB_PASS, DB_NAME);
if (!$conn) {
    die(json_encode(['error' => 'DB connection failed: ' . mysqli_connect_error()]));
}
?>
📁 auth/login.php — Login Handler
<?php
require '../config/db.php';
header('Content-Type: application/json');
$data = json_decode(file_get_contents('php://input'), true);
$email = mysqli_real_escape_string($conn, $data['email']);
$pass  = $data['password'];
$res = mysqli_query($conn, "SELECT * FROM users WHERE email='$email'");
$user = mysqli_fetch_assoc($res);
if ($user && password_verify($pass, $user['password'])) {
    session_start();
    $_SESSION['user_id'] = $user['id'];
    echo json_encode(['success' => true, 'name' => $user['full_name'], 'email' => $user['email']]);
} else {
    echo json_encode(['success' => false, 'message' => 'Invalid credentials']);
}
?>
📁 SQL — Create Tables
CREATE DATABASE emosense_db;
USE emosense_db;

CREATE TABLE users (
  id INT AUTO_INCREMENT PRIMARY KEY,
  full_name VARCHAR(100) NOT NULL,
  email VARCHAR(150) UNIQUE NOT NULL,
  phone VARCHAR(20),
  location VARCHAR(100),
  password VARCHAR(255) NOT NULL,
  trusted_email VARCHAR(150),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE emotion_history (
  id INT AUTO_INCREMENT PRIMARY KEY,
  user_id INT NOT NULL,
  emotion VARCHAR(50),
  confidence DECIMAL(5,2),
  detected_date DATE,
  detected_time TIME,
  FOREIGN KEY (user_id) REFERENCES users(id)
);

CREATE TABLE diary (
  id INT AUTO_INCREMENT PRIMARY KEY,
  user_id INT NOT NULL,
  entry_text TEXT,
  entry_date DATE,
  entry_time TIME,
  FOREIGN KEY (user_id) REFERENCES users(id)
);
📁 auth/register.php — Register Handler
<?php
require '../config/db.php';
header('Content-Type: application/json');
$data = json_decode(file_get_contents('php://input'), true);
$name  = mysqli_real_escape_string($conn, $data['full_name']);
$email = mysqli_real_escape_string($conn, $data['email']);
$phone = mysqli_real_escape_string($conn, $data['phone']);
$loc   = mysqli_real_escape_string($conn, $data['location']);
$trust = mysqli_real_escape_string($conn, $data['trusted_email']);
$hash  = password_hash($data['password'], PASSWORD_BCRYPT);
$sql = "INSERT INTO users (full_name,email,phone,location,password,trusted_email)
        VALUES ('$name','$email','$phone','$loc','$hash','$trust')";
if (mysqli_query($conn, $sql)) {
    echo json_encode(['success' => true]);
} else {
    echo json_encode(['success' => false, 'message' => mysqli_error($conn)]);
}
?>
